# Ajuri App - Automação Jurídica de Elite

O **Ajuri App** é uma plataforma completa de automação para advogados, focada em alta performance, inteligência artificial e gestão eficiente de leads.

## 📚 Documentação para Desenvolvedores

Para facilitar o entendimento e a manutenção do projeto, toda a documentação técnica foi centralizada e organizada na pasta `/documentation`:

1.  **[Arquitetura e Sistema](./documentation/01-ARQUITETURA-E-SISTEMA.md)**: Visão geral tech stack, mapa de páginas e funcionamento do cérebro IA.
2.  **[Configuração e Integrações](./documentation/02-CONFIGURACAO-E-INTEGRACOES.md)**: Guia de variáveis de ambiente, Google OAuth e conexões externas.
3.  **[Roadmap e Banco de Dados](./documentation/03-ROADMAP-E-BANCO-DE-DADOS.md)**: Plano de migração para Supabase, scripts SQL e visão de futuro.
4.  **[Integrações e Webhooks](./documentation/04-INTEGRACOES-E-WEBHOOKS.md)**: Detalhamento técnico do fluxo de dados e automações CRM.

---

## 🛠️ Início Rápido

1.  **Instale as dependências**: `npm install`
2.  **Configure o ambiente**: Crie um `.env.local` baseado no guia de configurações.
3.  **Inicie o servidor**: `npm run dev`
4.  **Acesse**: `http://localhost:3000`
